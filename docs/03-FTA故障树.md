## 5. 排故时怎么用这棵树
定位分支：先看现象属于哪一类（上电类→电源与功率；走不准→运动控制/编码器；通讯断→通讯与总线）；
剪枝：按「可验证性=实测 → 观察 → 替换」的顺序逐条排除，能测的先测；
禁止跳步：直接换驱动器（替换类）必须在交叉测试与器件级测量之后；
回流：每次现场确认的根因，回写到 rules.csv 的 cause，树会自动长出来。
本树是「结构性」的，不做概率计算。若要定量（求顶事件概率），需要每个基本事件的失效率 λ，手册不提供，只能用现场统计。

## 6. 专题：EtherCAT 设置引起的三类现象
有些「偶发」问题不在伺服本体，而在总线的时间基准上。下面三类现象都必须先排除总线因素，再去调增益。

### 6.1 逻辑链
总线因素 ──► 指令/采样时刻不均匀 ──► 速度环看到「假误差」
   │                 │                      │
   │                 ├─► 位置指令单周期跳变 ──► 位置偏差过大/超差
   │                 ├─► 周期性指令阶梯 ──────► 激发机械共振
   │                 └─► 采样抖动 ───────────► 速度抖动 / 电流波动 → 啸叫异响
   └─ 丢帧 / DC 失锁 / 看门狗 各自对应不同 AL Status Code

### 6.3 排查顺序（先总线、后参数、再机械）
看总线是否健康：工作计数器是否增长、丢帧计数、AL Status Code（0x0130/0x0134）；
看时间是否同步：DC 是否启用、SYNC0 周期、系统时间差（0x092C）；
看周期是否对齐：主站任务周期与总线周期是否整数倍；
再调参数：惯量辨识 → 增益 → 前馈；
最后看机械：共振频率、联轴器、皮带。
顺序反了会怎样：先调增益，可能把总线抖动放大成共振；先换机械，问题依旧——因为时间基准没解决。

### 6.4 通讯故障的分层定位（H0E.24~29）
跨域提醒：通讯问题不只在通讯层表现，会伪装成运动控制/机械现象—— 位置指令增量过大（主站任务周期与总线周期不整除）、速度抖动（DC 失锁/周期抖动）、 异响啸叫（同步抖动→电流波动）。遇到这三类，先按 §6.4 分层查通讯，再调增益。

## 7. 现象级故障树（无码，重构版）
树从现象进入，每一步是一个可验证的问题，落到具体参数和判据。 树根三叉：配置/参数错（能调）、硬件坏（能换）、选型越界（只能改型号或工况）。

### 7.1 精度类：定位不准 / 轨迹偏移 / 重复精度差
① 走固定距离，偏差是否成比例？
   ├─ 是 → 指令链量值错 → H05.07/09 齿轮比、H05.50/51（判据：偏差≈减速比）
   └─ 否 → ② 提高增益，跟随误差是否下降？
          ├─ 是 → H08.02 位置环增益低
          ├─ 否 → ③ 多轴插补时单轴是否都准？
          │        ├─ 是 → 两轴一致性 H08.19/21 前馈、加减速、背隙
          │        └─ 否 → ④ 反向打表，正反向差值？
          │                 ├─ 大 → 机械反向间隙
          │                 └─ 小 → 干扰/噪声（编码器屏蔽、接地）
          └─ 通讯侧：主站周期与总线周期不整除 → 位置指令增量过大（先查 §6）

### 7.2 动作类：不动 / 飞车 / 撞限位
① 看 6041h 状态字，是否 Operation enabled？
   ├─ 否 → 使能链断 → H02.00 模式、急停、STO、H03 DI 条件
   └─ 是 → ② 抱闸是否松开？（失电制动，通 24V 才松）
          ├─ 未松 → H02.09~12 抱闸时序、H04 DO、继电器
          ├─ 已松 → ③ 方向是否反？
          │        ├─ 反 → H02.02 旋转方向（判据：正向指令 CCW）
          │        └─ 正 → ④ 限位是否触发？
          │                 ├─ 是 → 限位开关/逻辑 H03 取反
          │                 └─ 否 → 飞车保护 H0A.12/55/57/58/59
          └─ 通讯侧：总线未进 OP、PDO 映射错（先查 §6）

### 7.3 波动/异响类：抖动 / 啸叫 / 振动
① 脱开负载，现象是否消失？
   ├─ 消失 → 机械侧：联轴器、皮带、减速箱背隙
   └─ 仍在 → ② 特定转速才响？
          ├─ 是 → 机械共振 → H09.23 陷波器 / H08.35 振动抑制
          └─ 否 → ③ 降增益是否消失？
                 ├─ 是 → H08.00/02 增益过高
                 └─ 否 → ④ 惯量比是否正确？
                        ├─ 否 → H08.15 惯量辨识
                        └─ 通讯侧 → DC 失锁/周期抖动（先查 §6）

### 7.4 功能类：按第 11 章功能失效
功能类先查配置对不对，再查硬件坏没坏。

### 7.5 选型越界（第三叉，先于一切参数排查）
选型越界靠调参压不住，只能改型号或改工况；先分清楚再动手。
