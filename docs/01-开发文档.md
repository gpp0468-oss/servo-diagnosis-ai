问题：伺服故障排查依赖老师傅经验——手册 800 多页、故障码 122 个、同一现象四五种原因，新人查不动。
做法：把「手册 + 现场经验 + 故障树」变成可检索、可推理、可审计、可自我更新的系统，AI 做初筛，人做决策。

## 3. 分类体系（双维度）
9 类故障源：电源与功率 / 通讯与总线 / 运动控制 / 编码器与反馈 / 参数与配置 / 电机与机械 / 安全与抱闸 / 驱动器本体 / 其他。
「电源与功率」的判定标准：能量「供给—变换—吸收—保护」通路上的元件/能量异常。
- 供给：缺相、过压/欠压、瞬时停电
- 变换：整流、软启、母线电容、IGBT
- 吸收：制动电阻、泄放管
- 保护：过流/过压/过载的保护动作
- 排除：阈值设置错 → 参数与配置；MCU/FPGA/加密芯片 → 驱动器本体；散热/安装 → 电机与机械。
为什么两维：现象与故障源是多对多耦合——同一个故障源（如 UVW 缺相）会表现为不同现象（位置偏差 / 堵转过热 / 缺相报警），一种现象（如定位不准）也可能来自多个故障源。单字段承载两个维度必然打架。

## 4. 数据资产

### 3.1 data/rules.csv —— 故障规则库（243 条，244 行含表头）
约束：同一 code 的所有行 category 必须一致（历史上出现过一条码 5 个类别，见 §7.3）。

### 3.2 data/cases.csv —— 现象级案例（17 条）
phenomenon, category, cause, confirm, action, verify, note
- note：现场证据（如“STO 瞬间端子电压未降到 0V”），会拼进检索切片；
- 用于没有故障码、只描述现象的场景。

### 3.3 feedback.csv —— 待审经验（运行时文件，不入库）
created, phenomenon, category, cause, confirm, action, verify, note, evidence, source, status, 通过
- status：待审核 / 已通过 / 已应用；
- evidence：分步诊断的状态变化时间线（自动带入）；
- 通过：勾选框，kb_apply.py 只处理勾上的行。

### 3.4 rag/chunks.jsonl —— 检索切片（1675 条）
{"text": "...", "source": "manual|note|rules|cases", "category": "...",
 "page": 666, "chapter": "16", "heading": "16.6.1 ..."}

### 3.5 rag/vectors.npy
1675 × 512 的 float32 矩阵，L2 归一化，行序必须与 chunks 完全一致。

### 3.6 eval.csv —— 评测集（20 条 + 5 条空白）
id, symptom, expected_code, expected_category, expected_cause_keywords, expected_action_keywords, source, note

## 5. 实现过程

### 5.1 提取手册文本
pypdf 逐页抽取，过滤运行页眉（‑681‑、「故障处理」）。845 页约 90 秒。

### 5.2 表格结构化
纯文本解析会把三列压成一行，导致「四种原因只抽到一种」。改用 pdfplumber 按表格边框解析，得到一行一原因的对应关系。

### 5.3 切分

### 5.4 建索引
- BM25：自研分词（单字 + 二元组），不依赖 jieba；
- 向量：bge-small-zh-v1.5 量化版（24MB），CLS + L2 归一化；
- 融合：0.5 × BM25归一化 + 0.5 × (cos+1)/2，大类命中 +0.05。

### 5.5 增量更新
新增经验只重算新增切片的向量（约 20 秒），不重跑 845 页 PDF。

### 5.6 假设生成
关键词表 + 口语别名（嗡嗡/异响→啸叫、走不到位→定位），不足时用大模型，再兜底通用模板。抱闸按失电制动（fail-safe）建模，见 §7.4。

### 5.7 故障树
fta_build.py 按大类生成 OR 树，叶节点带可验证性与页码，另加 EtherCAT 专题。

### 7.3 案例：分类不一致
第一版按「原因文本」逐行分类，结果 E908.0 一条码出现 5 个不同大类，分类准确率只有 45%。改为按 code 统一分类（用代码名称判定，EE 系列强制通讯）后升到 95%。

### 7.4 案例：抱闸方向搞反
最初假设写成「通电才闭合」，与实际相反。抱闸是失电制动：断电弹簧抱死，通电 24V 才松开。修正后假设改为「该夹时没夹住或夹太慢」，并补了 5 条案例与笔记 7.10 节。

## 8. 已知限制
量化向量模型语义有限，长尾同义词靠扩展补；
BM25/向量权重 0.5/0.5 未调参；
无 Rerank；
评测集是种子数据，指标偏乐观；
FTA 只做定性，无失效概率；
评测集与知识库靠脚本约束隔离，不是强制机制——归档前要自觉跑 check_leak.py。
