伺服驱动器原理学习笔记
目的：把「硬件怎么工作、控制环怎么稳、参数在调什么」串成一条线，能对上你手里那份手册第 16 章的故障现象。 整理日期：2026-11-01 来源：公开资料 + SV660N 手册，文末列出处。凡是标「工程经验」的是通用做法，不同品牌有差异，以手册为准。

## 0. 一页看懂
伺服系统 = 驱动器 + 电机 + 编码器，构成一个三环闭环：
位置指令 → [位置环 P] → 速度指令 → [速度环 PI] → 转矩/电流指令 → [电流环 PI] → PWM → 电机
                ↑                        ↑                          ↑
             编码器位置                编码器速度                  相电流采样
三句话记住：
电流环最内、最快（SV660 约 4.5 kHz），决定转矩响应；
速度环居中（约 3 kHz），决定抗扰和动态；
位置环最外、最慢，决定跟随误差和定位精度。
参数的本质，就是给这三个环「调性格」：快了容易抖，稳了容易慢；所有整定都是在稳定和响应之间找平衡。

## 1. 硬件原理

### 1.1 主回路：能量的路径
三相/单相交流 → 输入滤波 → 整流桥 → 母线电容 → 逆变桥(IPM/IGBT) → U/V/W → 电机
                                   ↑                    ↓
                              制动单元/制动电阻 ←── 再生能量
为什么要制动电阻：电机减速时变成发电机，能量回灌母线，电压升高。惯量大、频繁启停、垂直轴最容易触发过压。

### 1.2 控制回路：信号的路径
- 主控芯片（DSP/FPGA）：跑矢量控制（FOC）、三环 PI、PWM 生成、总线协议；
- 电流采样：霍尔或采样电阻 + ADC，在每个 PWM 周期采两相电流，第三相由 ia+ib+ic=0 推；
- 编码器接口：ABZ 增量或串行绝对值（SV660 支持到 26 位），提供位置与速度；
- 隔离：光耦/数字隔离器把功率侧与控制侧分开，防止干扰；
- 电源：多路低压（±15V、5V、3.3V）给控制与驱动电路。

### 1.3 为什么开关频率很重要
PWM 把直流「切成」正弦：开关频率越高，电流纹波越小、电流环带宽越高、噪音越小；代价是开关损耗和发热。
这也解释了两个现场现象：
- 载频调低 → 电机啸叫变大、电流纹波变大；
- 载频调高 → 驱动器发热、可能降额。

### 1.4 保护链路
过流（硬件比较器 + 软件）、过压/欠压（母线分压采样）、过热（NTC）、短路/接地（硬件检测）、编码器异常（通信超时/校验）。这些保护大多先于软件动作，所以有些故障复位后仍会立刻重现——因为根因还在。

## 2. 自动控制原理

### 2.1 被控对象：永磁同步电机
简化模型（d/q 轴，id=0 控制）：
u_q = R i_q + L_q di_q/dt + ωₑ ψ_f
Tₑ = 3/2 p ψ_f i_q
Jdωₘ/dt = Tₑ - T_L - Bωₘ
三个式子对应三件事：
电压方程 → 电流环要克服电阻和电感；
转矩方程 → 转矩正比于 q 轴电流，所以「控制电流就是控制转矩」；
机械方程 → 惯量 J 越大，同样的转矩加速越慢。

### 2.2 矢量控制（FOC）在干什么
把三相电流通过 Clarke/Park 变换，变成随转子旋转的 d/q 两个直流量：
- d 轴电流控制磁场（通常给 0，即「不弱磁」）；
- q 轴电流控制转矩。
好处：交流量变成直流量，PI 调节器才能做到「无静差」。这是伺服比变频器响应快、低速力矩稳的根本原因。

### 2.3 三环的带宽与稳定性
工程上的经验法则：
f_(电流环) ≈ 5∼10 × f_(速度环),   
f_(速度环) ≈ 5∼10 × f_(位置环)
内环必须比外环快得多，否则外环「指挥不动」内环，系统会振荡。
PI 参数对稳定性的影响：
限制增益上限的四个因素：
机械共振（联轴器、丝杠、皮带的一阶/二阶模态）；
采样与计算延迟（PWM 周期、电流采样延时）；
滤波器引入的相位滞后；
惯量比过大（负载惯量远大于电机惯量）。

### 2.4 惯量比：为什么它是「整定的天花板」
惯量比 = (J_(负载折算到电机轴))/(J_(电机))
惯量比越大，同样的增益下系统越容易振荡（因为负载像一个「晃动的弹簧」）。所以：
- 惯量比大 → 只能降低增益 → 响应变慢、到位慢；
- 惯量比小 → 可以提更高增益 → 更快更硬。
这就是「刚性等级」参数的物理基础：它本质上是一组按惯量比预设好的增益组合。

### 2.5 前馈与滤波
- 速度前馈 / 转矩前馈：不等误差出现就提前给指令，减小跟随误差；前馈过大会过冲；
- 陷波滤波器（Notch）：对准机械共振频率「挖一个坑」，抑制特定频率的振荡，不影响其他频段；
- 低通滤波器：压制高频噪声，但会带来相位滞后，降低带宽。
正确顺序是：先抑振（陷波/机械），再提增益；反过来先降增益，会把响应一起吃掉。

## 6. EtherCAT 总线

### 6.1 为什么工业现场选它
一句话：EtherCAT 不是「更快的以太网」，而是「让以太网帧在经过每个从站时顺手读写数据」，所以一帧能带几百个轴的数据。

### 6.2 基本原理：On-the-Fly
主站发出一帧，从站 1 收到后不停顿，边转发边把属于自己的数据读走/写进去；帧依次经过所有从站，最后返回主站。
主站 → 从站1 → 从站2 → 从站3 → … → 返回主站
        ↑读写    ↑读写    ↑读写
工作计数器（Working Counter）：每个子报文带一个计数器，从站成功读写就 +1，主站靠它判断「这一帧有没有被正确处理」。
两种寻址：
- 物理寻址：按站号（Auto Increment 或配置站号）读写某个从站的寄存器；
- 逻辑寻址：用 FMMU 把「过程数据的逻辑地址」映射到「从站物理内存」，主站只关心逻辑地址，不关心数据在哪个从站。
拓扑：线型、环型（冗余）、树型（带分支的 EBUS），支持热插拔（部分型号）。

### 6.3 ESC 寄存器：从站的大脑
ESC（EtherCAT Slave Controller）是每个从站里的专用芯片（或 FPGA IP），对外表现为一片寄存器空间：
具体偏移以 ESC 数据手册为准（不同厂家 IP 核略有差异），但分组是固定的。

### 6.4 分布式时钟（DC）：多轴为什么能同步
问题：每个从站有自己的晶振，跑久了会漂；多轴插补要求「同一时刻采样、同一时刻输出」。
做法：
选第一个支持 DC 的从站作为参考时钟；
主站周期性发 ARMW/FRMW 命令，把参考时间读出来、再写回各从站；
各从站算出自己的偏移（offset）和漂移（drift），补偿本地时钟；
到同步时刻，各从站同时拉 SYNC0 信号，锁存输入/更新输出。
t_(系统) = t_(本地) + t_(偏移) + t_(传播延迟)
精度可达 100 ns 量级，这就是「多轴同时到位」的底层保证。

### 6.5 通讯建立过程：四步状态机
INIT(1) → PREOP(2) → SAFEOP(4) → OP(8)
完整启动流程：
主站扫描总线（BRD 广播），发现从站、读拓扑；
给每个从站分配站地址（写 0x0010）；
读 EEPROM/SII，拿到厂商 ID、PDO 映射；
配置 SyncManager 和 FMMU；
写 AL Control 请求 PREOP，用 CoE 下发参数（如 0x6060 运行模式、0x6098 回零方式）；
请求 SAFEOP，检查输入数据；
请求 OP，开始周期通讯。
排障提示：总线起不来，先看 AL Status Code（0x0134），它直接告诉你卡在哪一步——比猜「是不是线松了」快得多。

## 7. 现象级失效：定位不准、啸叫、偶发过流

### 7.1 定位不准（走不到位 / 过冲 / 重复精度差）
按「先机械、再参数、后电气」的顺序查：
典型判断：
- 每次都差同一个固定值 → 电子齿轮比/脉冲当量算错；
- 反向时差一点、正向不差 → 机械反向间隙；
- 到位慢、跟随误差大 → 位置环增益低或前馈不足；
- 偶发跳变 → 编码器线干扰（屏蔽、走线）。

### 7.2 电机啸叫（高频噪音 / 抖动）
顺序很重要：先抑振（陷波/机械），再提增益。反过来先把增益降到底，会把响应一起吃掉，表现为「不叫了，但到位很慢」。

### 7.3 偶发性过流
偶发 = 不是一直发生，说明和工况、温度、振动、干扰相关。按概率排查：
一个经验：偶发过流如果总在「加速/换向/急停」瞬间出现，八成是增益或惯量；如果随机出现且伴随位置跳变，八成是编码器干扰。

### 7.4 对照手册 16.8：遗漏清单
手册 16.8「常见问题及解决建议」共 12 类现象，我前面只写了 3 类（定位、啸叫、过流），遗漏的是「上电类」「连接类」「操作类」——而这恰恰是现场最高频的。
手册给的第一条方法论（16.8.1）：排障流程按序号从小到大依次排查。翻译过来就是：先外后内、先易后难、先便宜后贵——这个顺序本身就是「原理」：外部接线和电源问题的概率远高于驱动器内部损坏。

### 7.5 上电与显示类（16.8.2 / 16.8.3 / 16.8.5 / 16.8.8 / 16.8.13）
可量化的阈值（建议背下来）：
- 输入：220V 机型 180–264VAC；380V 机型 342–484VAC；
- 母线正常：220V 机型约 235–378V；380V 机型约 451–689V；
- 控制电欠压阈值 H01.78：220V 约 190V、380V 约 380V。

### 7.9 专题：EtherCAT 设置会不会导致「位置指令增量过大 / 共振 / 速度抖动」
会，而且现场经常误判成伺服参数问题。判断的关键是：先看时间基准，再看控制参数。
诊断用的四个寄存器/状态（ESC 侧）：
逻辑链：
总线时间基准不稳 → 指令/采样时刻不均匀 → 速度环看到「假误差」→ 电流周期性强
        │                    │
        ├→ 位置指令单周期跳变 → 位置偏差过大
        ├→ 指令阶梯 → 激发机械共振
        └→ 采样抖动 → 速度抖动
结论：凡是「偶发」「周期性」「只在多轴联动时出现」的抖动/增量异常，先排总线（DC、周期、丢帧），再排参数（增益、惯量），最后排机械。顺序反了，越调越乱。
参考：郇极、刘艳强《工业以太网现场总线 EtherCAT 驱动程序设计及应用》（北航出版社），书中系统讲了 EtherCAT 协议、ET1100 从站芯片、CoE/SoE 对象字典与主从站驱动，可作为 ESC 寄存器与状态机的深入读物。

### 7.10 抱闸：失电制动，不是得电制动
这是最容易搞反的一条：伺服电机的抱闸是「失电制动（fail-safe）」——断电时弹簧把闸片压紧，轴被抱死；通电 24V 才克服弹簧、松开抱闸。
所以：
STO 触发后下坠的排查顺序（垂直轴）：
闭合延时：STO 到抱闸真正夹紧有时间差，负载在这段时间内自由下落。测延时、量下坠距离；缩短延时或加第二重制动；
保持力矩不足：闸片磨损、油污、气隙过大，夹紧但摩擦力不够。断电手动加载测保持力矩；
回路未断电：继电器粘连或 DO 常输出，抱闸一直接着 24V，等于一直松开。STO 瞬间测端子电压是否到 0V；
时序参数：抱闸开合时序与 STO 动作顺序不匹配；
选型：垂直轴重力矩超过抱闸额定保持力矩。
一句话：抱闸故障不是「没通电」，而是「该夹的时候没夹住，或者夹晚了」。

### 9.2 基本控制参数（H02）：决定“驱动器怎么工作”
这一组是“功能对不对”的总开关，很多“不动/方向反/上电丢原点”都能在这里找到原因。

### 9.5 位置控制（H05）：位置是怎么被“定义”出来的
这组参数的共同问题只有一个：位置是个物理量，但控制器里只是一串脉冲数，怎么把它们对上？
H05.07 / H05.09 电子齿轮比分子 / 分母 —— 为什么存在？
编码器输出的是脉冲计数（物理单位），用户关心的是毫米、角度、行程（工程单位）。两者之间需要一把“尺子”换算。电子齿轮比就是这把尺子：用户单位 = 脉冲数 × 分子 / 分母。
没有它，上位机发一个单位，负载走多远完全不可知——这就是“走不到位/距离不对”的头号根源。
H05.50 / H05.51 机械齿轮比分子 / 分母 —— 为什么存在？
绝对值旋转模式下，负载转一圈 ≠ 电机转一圈（中间有减速机）。要算出“负载转一圈 = 多少个编码器脉冲”，必须告诉驱动器减速比。公式 负载一圈脉冲 RM = 编码器分辨率 RE × H05.50 / H05.51。
为什么电子齿轮比和机械齿轮比要分开？ 一个是“编码器↔用户单位”，一个是“电机↔负载”，两个比例物理意义不同，混在一起就调不清。
H05.21 定位完成阈值 —— 为什么存在？
“到达目标”从来不是精确相等，位置总有几微米残余偏差。这个阈值定义“多近算到”。太小 → 永远报“没到位”；太大 → 没到就说到了。它是一个工程容差，不是精度。
H05.30 / H05.35 / H05.36 回零三件套 —— 为什么存在？
编码器只知道相对位移，要建立“绝对原点”必须先做一次回零：
- H05.30：谁触发回零（上位机不能发 6040h bit4 时，本地触发）；
- H05.35：回零超时保护（找不到原点不能无限找，超时报 E601.0）；
- H05.36：回零完成后把当前位置定义成哪个值（原点可微调）。
H05.04 / H05.05 / H05.06 指令滤波 —— 为什么存在？
位置指令可能阶跃突变，机械有惯性，突变=冲击。滤波在源头平滑指令，代价是响应滞后——平滑与快速永远是矛盾，滤波参数就是在两者之间找点。
小结：H05 组回答的是“位置的量化”——把脉冲翻译成位移、把相对位移锚定到绝对原点、把突变指令平滑成可执行轨迹。

### 9.6 速度与转矩（H06/H07）：物理量怎么被“约束”和“保护”
H06 速度组 —— 为什么存在？
速度不能想多快就多快、想怎么变就怎么变：
关键理解：H06 组大量参数标注 “EtherCAT 模式下无效”。为什么？因为总线模式下，速度指令、加减速、限速都由上位机直接给（限速走 607Fh、斜坡走 6083/6085h）。所以 H06 组本质是本地（面板/端子）速度模式专用的参数——同一功能，本地用 H 组、总线用对象字典。这是理解“两套编号”最直观的例子。
H07 转矩组 —— 为什么存在？
转矩对应“力”，直接关系机械安全和电机寿命：
弱磁为什么存在（H07.26–28）？
永磁同步电机的反电动势随转速升高而升高，当反电动势逼近母线电压时，电流灌不进去，转速上不去了。弱磁就是主动注入一个“去磁电流”，压低反电动势，从而扩展高速运行区间。代价是：负载率上升、效率下降、电流纹波变大（H07.24 弱磁深度）、有退磁风险（H07.25 退磁电流要厂家确认）。
小结：H06/H07 组回答的是“速度、转矩这两个物理量的约束与保护”——限速、限转矩、斜坡、飞车保护、弱磁扩速，都是“允许在什么范围内、以什么速度变化”。

## 10. 手动增益调整（第 9 章 9.4，深度）

### 10.0 先建立模型：三环串级
伺服控制是三个环从外到内套起来：位置环 → 速度环 → 电流环。
位置指令 →[位置环]→ 速度指令 →[速度环]→ 转矩指令 →[电流环]→ 电机 → 负载
          ↑                ↑
          编码器反馈        速度反馈
核心规则：越靠内的环，响应必须越快。内环比外环慢，系统就不稳定。
- 电流环（转矩环）驱动器出厂已调好，一般不碰；
- 要调的是速度环增益、位置环增益、以及一堆“辅助”参数；
- 为什么会有那么多辅助参数？因为纯三环有四个天生缺陷：噪声、滞后、扰动、摩擦。9.4 的每一节，都是在补其中一个缺陷。

### 10.1 基本参数（9.4.1）：三环的“油门”
三条铁律（都来自手册）：
500 ≤ H08.00 × H08.01 ≤ 1000——积分和比例要配套；
速度环频率应为位置环的 3~5 倍（例：H08.00=40Hz → H08.02 应在 50~84Hz）；
转矩滤波截止频率应高于速度环频率 4 倍（例：H08.00=40Hz → H07.05≤1ms）。
为什么会有这三条？ 环与环之间要有“带宽间隔”，否则两级同时振荡、互相放大。
边界：H08.00 太大→啸叫/振动；H08.01 太大→偏差归不了零（512ms 时积分无效）；H08.02 太大→振荡；H07.05 太大→电流环响应变慢（停机振动时反而要加大 H08.00、减小 H07.05）。

### 10.2 增益切换（9.4.2）：一组增益不够用
为什么存在：运行时要高增益跟踪，静止时要低增益抑振——一对矛盾，靠切换解决。
第二增益 = H08.03/04/05 + H07.06（默认比第一增益高，如第二速度环 75Hz vs 第一 40Hz）。
为什么要有“等级 + 时滞 + 延迟”三个？ 防止在阈值附近高频抖动：超（等级+时滞）才切过去，低于（等级−时滞）持续 H08.10 才切回来。

### 10.3 位置指令滤波（9.4.3）：在源头平滑
为什么存在：上位机指令不平滑（没做加减速、脉冲频率低、齿轮比≥10 倍），突变会被位置环放大成冲击。
边界：滤波越大越平滑，但响应延迟越大——平滑和快速是对矛盾。

### 10.4 前馈增益调整（9.4.4）：不用“等误差”就提前给
为什么存在：反馈是“先有误差、再纠错”，天生滞后。前馈把指令的导数（速度、转矩）直接加进内环，提前补偿，因此能减小跟随误差，而且不增大反馈增益、不牺牲稳定性。
速度前馈（减小固定速度时的位置偏差）：
调法：先固定 H08.18，H08.19 从 0 渐增，找到见效点；再回头微调 H08.18，反复折中。
零相位控制（H05.19=3）+ H08.17 零相位延时时间：专门补偿“启动瞬间”的位置偏差。
转矩前馈（减小固定加减速时的偏差；速度模式减小速度偏差）：
边界：H08.21 过大→过冲；此时不降 H08.21，而是增大 H08.31（扰动截止频率）来压过冲。

### 10.5 伪微分前馈 PDFF（9.4.5）：给速度环换一种控制方式
为什么存在：默认 PI 速度环，要么响应快但易超调，要么积分强但响应慢。PDFF 想两者兼得。
边界：速度反馈出现过冲时，H08.24 从 100 渐减。本质是在“比例”与“积分”之间调配。

### 10.6 转矩扰动观测器（9.4.6）：把“看不见的扰动”抵消掉
为什么存在：外部扰动（负载突变、切削力）只能等误差出现再纠。观测器估计扰动、前馈抵消，平衡响应与稳定。

### 10.7 模型跟踪（9.4.7）：让实际响应贴合理想模型
为什么存在：直接把指令喂给一个“理想模型”，让实际位置跟随模型输出，提高响应、缩短定位时间。仅位置模式。
前提：惯量值必须准，偏差大会振。通常由 STune/ETune 自动设定，不满意才手动。

### 10.8 速度观测器（9.4.8）：把速度反馈里的噪声滤掉
为什么存在：速度反馈含高频噪声，限制了增益上限。观测器滤掉高频分量，在更高增益下也不振，从而缩短定位时间。
前提：先设准 H08.15。

### 10.9 摩擦补偿（9.4.9）：克服“起步那一下”
为什么存在：静摩擦造成低速死区、爬行、反向过象限误差；垂直轴还有重力造成启动下坠。
为什么正负分开？ 摩擦方向与运动方向相反，正反转补偿符号不同。

### 10.10 调整顺序（第 9 章 9.5）
所有模式统一顺序：惯量辨识 → 自动增益调整 → 手动增益调整。
跳步的后果：惯量比 H08.15 错，后面所有增益、前馈、观测器都建立在错的基线上，怎么调都不对。

### 10.11 H08/H09 参数为什么存在（一张心智模型表）
H08 增益组 = 把三环调好。 每个参数对应闭环控制的一个缺陷：
H09 自调整组 = 让机器自己调好 + 补非线性缺陷。 它管两类完全不同的东西：
一句话总结：
- H08 解决“线性的闭环问题”——响应、稳态误差、带宽、扰动、噪声；
- H09 解决“非线性和自动化问题”——共振、重力、摩擦这些不是比例增益能解决的，以及“让不熟练的人也能一键调好”。
这也是为什么排故时：振动先想 H09（共振/陷波）还是 H08（增益过大）——啸叫、特定转速共振多走 H09 的陷波；全转速发飘、过冲走 H08 的增益/前馈。

### 11.2 转换因子（11.1）
由 H05.07 / H05.09（电子齿轮比分子/分母） 与 H05.50/H05.51（机械齿轮比）共同决定「一个指令单位 = 多少负载位移」。它决定了上位机发多少个单位、负载走多远。
这是“走不到位”类问题的第一嫌疑人：齿轮比或指令单位设错，距离会成比例偏差。带减速机时负载位移很小，现场常被描述成“电机不动”——第一现场看到的是负载，不是电机。

### 11.3 状态机（11.2）
Switch on disabled → Ready to switch on → Switched on → Operation enabled
- 控制字 6040h 发命令，状态字 6041h 看状态；
- 卡在某一级，先查使能链：急停、STO、模式、DI 条件、抱闸；
- 状态字里还有跟随误差、内部限位等标志位，是判断“为什么不动作”的第一手信息。

### 11.4 六种控制模式（11.3–11.9）
模式选错是最基础也最常见的配置类故障：上位机按 CSP 发，伺服在 PP 模式，表现就是“指令在变、电机不动”。
每一节的结构都一样：配置框图 → 推荐配置 → 相关功能设置 → 相关参数，排故时按这个顺序核对。

### 12.1 指令链六环
上位机指令 → 指令单位/齿轮比 → 编码器分辨率 → 位置环 → 速度环 → 电流/转矩 → 机械
任何一环出错，现象都可能是「走不到位」：
结论：不要一看到「定位不准」就调增益，先确认指令链前四环的量值对不对。

### 12.2 保持类失效（现归入功能类）

现场工程师看到的是结果（负载没动、产品尺寸不对），不是原因（电机没转）。知识库记录现象时应保留第一现场表述，再由系统去做归因——否则会把「观察」和「推断」混在一起，检索也会失准。

负载转动惯量（19.1.5）——选型最容易错：惯量比越大响应越差、越易不稳；超允许惯量比 → 减速过压报警，内置制动电阻时 → 过载报警。处置顺序：降转矩限制 → 减减速曲率 → 降最高转速 → 仍不行加外置制动电阻。

### 14.5 选型 × 排故
一句话：报故障先分清“参数错”还是“选型越界”——越界靠调参压不住，只能改型号或改工况。

### 9.10 故障与保护（H0A/H0C）：什么算故障、何时报、报之前要不要先保护
保护组的核心不是“报码”，而是回答三个问题：① 什么量超限算故障；② 是立即报还是要先滤噪再报；③ 报之前能不能先自我挽救。
缺相保护（H0A.00 / H0A.51）——为什么有滤波次数？
缺相判断靠采电流波形，而电流里有噪声。若“少一个周期就报”，会频繁误报；H0A.51 让“连续 N 次确认缺相”才报——用时间换准确。
过速 / 飞车保护（H0A.08/70 过速；H0A.12/55/57/58/59 飞车）——为什么分两套？
- 过速：转速超过电机/机械极限，直接报（H0A.08、H0A.70）；
- 飞车：更危险——不是“转速高”，是“失控”：指令没让转、它自己转，或转矩模式下负载突轻导致速度狂飙。所以飞车要用电流判据 + 速度判据 + 滤波 + 检出时间四者组合，既要快速捕捉、又不能把正常加速误判成飞车。
过载 / 过热（H0A.04 增益、H0A.18 IGBT 温度、H0A.32/33 堵转过温、H0A.52 编码器温度）——为什么这么多“温度”？
过载保护本质是热模型：电流积分近似发热。不同器件热时间常数不同——IGBT 快、电机绕组慢、编码器有温度上限、堵转（有电流不散热）最危险。所以各自独立阈值，且 H0A.26 允许屏蔽（调试/特殊场合），H0A.04 增益按电机实际发热调。
STO 容错（H0A.73/74/75）——为什么两路还要滤波？
STO 是双通道安全信号，两路本应一致。但两条通道的硬件路径天然不对称：外部电源接线、电源本体、安全继电器、继电器本身都存在差异，导致两路信号到达时间/电平不一致。若不一致就立即触发会误停，所以用 H0A.74 滤波时间，让“持续不一致”才判故障——滤掉的是两路硬件差异，不是抖动。
电压跌落 / 瞬停（H0A.81~84）——为什么先限转矩、再保持、再取消？
母线电压跌落时，若仍按原转矩输出，电流会飙、会失控。所以：H0A.81 使能检测 → H0A.82 跌落后限制转矩 → H0A.84 瞬停保持时间 → H0A.83 取消转矩限制的时间。这是一条时序保护链，不是单个动作。
故障等级（H0C.80）/ 警告保持（H0C.00）/ 复位延迟（H0A.56）——为什么有“延迟”？
复位立即生效的话，故障根源还在就马上又触发、反复报警；延迟让系统喘口气，也给上位机留出处理时间。
一句话：H0A 是“在故障发生前，用阈值+滤波+时序把系统拉住”；报码是最后手段。

### 9.14 EtherCAT DC 同步（为什么、怎么调、怎么定位）
DC 要解决什么？ 多从站要“同时动作”。分布式时钟（DC）让所有从站内部时钟纳秒级对齐，用 SYNC0 硬件信号同时触发采样/输出，避免“帧到得早的先动、到得晚的后动”。
为什么主站也要跟着调（DCM）？ 主站定时器（如 8254）和从站晶振都做不到精确周期，二者有漂移。若主站不跟随从站时钟，主站发帧时刻与从站 SYNC0 脉冲的间隔会漂移，产生抖动。DCM 是闭环：每周期读“主站时间 vs 参考从站时间”的差 → PI 控制器算修正量 → 调整主站定时器（主站转换）或写从站寄存器 0x920（总线转换）。
为什么要调 DC 算法？ 原始算法是 sign(偏差) 的极弱比例 + 漂移率平均：100μs 初始偏差要 20~50 秒才收敛、无积分项有残余偏差。改标准 PI（Kp≈0.05）后几十毫秒收敛、稳态 ±10ns。
三种同步模式：Free Run（各跑各的，无同步）｜ SM-Sync（帧到达触发，越靠后的从站越晚）｜ DC-Sync（SYNC0 硬件中断，纳秒级，优化模式输出抖动 ≈15ns）。优化 DC = 帧到达（SM Event）先预处理 → SYNC0 触发只“取走+输出”。
同步丢帧为什么发生？ 帧传到尾端从站有物理传输时间；SYNC0 触发太早（shift time 偏置太小），尾端从站在 SYNC0 时还没拿到数据，就判“丢帧”。解法：调大偏移时间 shift time。
H0E.24 ~ H0E.29 分层定位通信故障（从底向上）：
H0E.29 → H0E.24 正是“物理→链路→转发→从站→同步”的排查顺序，配合 H0E.33（状态机/端口）与 H0E.35（AL 故障码）。
一句话：DC 是一个闭环时钟同步系统；调算法=换更快的控制器；丢帧计数=分层定位从物理到同步的问题。

## 15. 安装与接线（第 6 章）

### 15.1 接线注意事项（6.1）
- 安全：必须用 TN/TT 星型电网，严禁 IT 电网；UVW 端子严禁接三相电源/工频；
- 抗干扰：动力线与编码器线分开走线、屏蔽层接地、必要时加磁环；
- 线缆使用：按规格选线径，抱闸 24V 线径 ≥0.2mm²（750W 内）或 ≥0.8mm²（750W 以上）。

### 15.2 端子体系（6.2~6.10）
关键理解：端子不是“插上就行”，每类端子有配套的抗干扰要求——动力线要屏蔽接地、EtherCAT 线要 CAT7 屏蔽（ISO/IEC11801）、编码器线要和动力线分开。大量“偶发”故障是接线不规范导致的干扰，先查接线再看参数。

### 15.3 接地（6.9）
单设备接地、多设备接地、控制柜系统接地三种；接地不良 → 共模干扰 → 编码器信号异常、通讯丢帧。

### 15.4 选配件（6.10）
制动电阻、电源滤波器、浪涌抑制器——都是“被动保护”，接错或漏接会表现为过压、过流、干扰。
